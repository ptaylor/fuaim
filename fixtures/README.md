# fixtures

The synthetic library the browser half is developed against, before a real scan
exists — the same way físeán's was. Everything the browser shows here is
invented audio until the indexer replaces the fixture.

Planned contents, generated by a `make_fixtures.py` (to be written):

- `media/` — a handful of small generated audio files (a few seconds each) across
  the target formats, enough to exercise playback and the proxy.
- `fuaim-index/` — a committed index of `manifest.json`, `audio/<id>.json`,
  `wave/<id>.png`, `spec/<id>.png` and any proxies, so `fuaim browse` works from
  a fresh clone with no scan and no model.

Not created yet — the scaffold has no code to generate them.
